AQUASHELLA — a catalogue photograph of an impossible gadget: a miniature
umbrella device that keeps a goldfish dry. A chrome stand clamped to a glass
fishbowl holds a deep-red canopy directly over one orange goldfish, with a
single product tag as the only accessory. The image is rendered
deterministically with PIL (build_image.py) into entry.png (1024×1024), and
main.ts copies it to the output directory at run time.
